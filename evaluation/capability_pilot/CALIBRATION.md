# 9건 캘리브레이션과 양식 수정

각 유형의 `CP-Tn-01`이 캘리브레이션 부분집합이다. 초기 입력/답안 초안을
일괄 작성한 뒤 이 9건의 구조·지표·대안 경계를 점검했고, 확장 후보 전체의
독립 AI 반례 점검과 함께 입력/양식 결함을 수정했다. 사람 최종 판단이나
정식 골드 승인, 모델 성능 측정으로 간주하지 않는다. 단계별 사람 검수 통과를
선언하지 않으며 전체 패키지를 provisional 검수 준비본으로 제시한다.

## 확장 중 발견한 결함과 조치

- T2/T9의 초안 6건이 모두 복합인 문제가 나와 단일 조건/단일 문서 사례를
  각각 1건 추가했고, T9에는 출력 절단과 별개인 계약 미확정 보류를 추가했다. 최종 57건이며 9건은 별도 추가 표본으로 세지 않는다.
- Rich는 호환성 절이 이미 설치 직전이었다. **무수정**도 타당한 대안으로
  보완했다. 개선 필요성을 가정해 불필요한 이동을 강제하지 않는다.
- T4-03의 고급 안내 명칭/목적지를 일치시키고 문서 간 이동 사례에 실제
  논리 경로를 넣었다. T5-02는 보호 코드 줄을 유지하면서 필요한 헤더와
  함께 분할할 수 있음을 명시했다. 무관 기존 앵커 결함은 교정 의무로 삼지 않는다.
- Express의 두 진입점 중 Quick Start에는 Node18+가 없었다. 필요한 반복과
  설치 전제의 현지 접근을 보완하되 generator@4와 설치 명령을 합치지 않는다.
- T9-05는 실제 작업 실행 방법 완성이 아닌 조건·중단·상태 탐색으로
  과업을 명시했다. 읽기 전용 report는 전체 반환에 포함하되 편집은 금지했다.
- T9-06은 입력의 사실 보류와 결과 절단을 분리했다. Q는 미평가이며
  D 정답 보류 적중으로 세지 않는다. 미응답/실행오류도 마찬가지다.

## 지표와 검증 범위

R ID 수가 필수 판단 recall의 고정 분모이며 F ID 수는 명시된 금지 기회 분모다.
제안 precision은 실제 관측된 모든 평가 가능 제안이 분모다. Q 5축에는
0/1/2/3 관찰 앵커와 사례별 보호 사실/과업 기준을 함께 제공한다.
각 대안의 효과가 필수 판단과 금지 결과 회피를 모두 포함하는지 기계 점검한다.
이 효과 선언의 의미적 참/거짓은 AI 반례와 사람 검수 대상이다.

별도 구현 검토에서 중복 판단 ID로 분모가 축소되는 결함, 본문/인용/독립 선언이
부실한 AI 리뷰가 집계되는 결함을 재현했다. 회귀 테스트를 먼저 실패시킨 뒤
ID 유일성과 raw review 스키마를 보강했다. 이는 구조 회귀이며 D/Q 채점기의
의미 타당성 입증이 아니다. 현재 모델 실행과 평가자 점수는 없다.
