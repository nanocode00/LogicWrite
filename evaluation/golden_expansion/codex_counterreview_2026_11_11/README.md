# Codex 독립 AI 반례 검토 — 사용자 최종 검토 대기

사용자 요청에 따라 기존 검토와 같은 **별도 Codex 서브에이전트** 방식으로 17건을 다시 검토한다. [검토 패키지](REVIEW-PACKAGE.md)가 이번 PR의 현재 검토 자료다. 이전 Qwen 결과 및 AGY 실패 기록은 이전 디렉터리에 그대로 보존하며 이번 Codex 결과에 합산하지 않는다.

## 증거 경계

세 검토자에 대화 이력을 상속하지 않는 `fork_turns=none`을 적용하고 입력 전용 요청만 전달했다. 각 요청에는 해당 사례 JSON 전체, 사용자 최초 판단·근거·입력 SHA-256만 포함한다. answers, 기존 AI 사전 검토, 개발용 골드, Qwen 결과, 다른 검토자의 반례는 제공하지 않았다. 각 검토자에게 임시 요청 파일만 읽도록 명시했다. 이는 문맥·읽기 지시의 격리이며 OS 접근 권한 차단을 주장하지 않는다.

`*.request.json`은 검토자에게 전달한 전체 입력 전용 요청의 사본, `*.raw.json`은 검토자가 실제 생성한 결과 bytes, `*.execution.json`은 부모가 관찰한 배정·완료·요청/응답 해시·시간 기록이다. `agent-messages.json`은 실제 완료 메시지 기록이다. `*.tool-trace.json`은 호스트의 각 자식 세션 로그에서 추출한 실제 도구 호출·출력 및 최종 메시지다. 시스템/개발자 지시와 reasoning은 제외했다. 이 기록에서 요청 파일만 읽고 결과 파일만 쓰는 명령, 전체 분할 열람과 분석 실행을 확인했다. 호스트 `turn_context.model`은 세 검토자 모두 **gpt-6.1-sol**이다. 모델 자기 보고는 원시 결과 그대로 보존하고 호스트 관측과 구분한다. 부모의 실제 collaboration 배정·완료 관측을 기록하며 암호학적 모델 인증을 주장하지 않는다. 과거와 같은 실행 방식이며 과거와 동일한 모델 weights임을 보증하지 않는다.

원문 입력 파일은 변경하지 않으며 `initial-judgments.json`은 이전 사용자 최초 판단 기록과 동일 bytes다. 각 사례의 인용을 실제 JSON pointer가 가리키는 문자열과 대조한다. JSON·ID·SHA·인용·누락 없는 사례 범위는 기계 검증하고, 반론의 타당성과 최종 선택은 사람이 검토한다. 모델 설명과 권장 라벨 간 명백한 모순은 완료 집계에서 제외한다.

SP-015는 전체 입력 및 모든 본문을 제공하며, 검토자는 잘리지 않은 분할 열람과 전체 diff/구조 분석 방법을 기록해야 한다. 해당 방법은 실행 증거와 함께 검수하되 사람이 전체 의미 검토를 대체했다고 단정하지 않는다.

## 재현·검증

```sh
python3 evaluation/golden_expansion/codex_counterreview_2026_11_11/validate.py
python3 evaluation/golden_expansion/codex_counterreview_2026_11_11/regression.py
```

validate.py는 모델을 호출하지 않고 보존 파일 해시, 입력 전용 요청, 초기 판단 연결, 원시 결과, 인용 및 빈 사람 응답 필드를 재검증한다. 실제 독립 검토 재실행에는 Codex collaboration 도구로 새 `fork_turns=none` 검토자를 생성하고 해당 `*.request.json`만 전달해야 한다. 이전 결과·이력을 상속하지 말고 새 attempt 경로에 저장한다. 이미 성공한 검토자는 재호출하지 않는다.

사용자는 각 반론에 동의·반박·보류를 선택할 수 있다. 사용자 최종 판단과 개발용 골드 포함 승인은 기록하지 않는다. 기존 G3/G4 골드 및 평가 자료를 변경하지 않는다.

## 결과와 검증

Codex 서브에이전트 3개를 실제 실행하여 17건 검토 완료, 실패 0건, 최초 판단과 권장 판단 불일치 0건이다. 권장 분포는 PRESERVED 8 / VIOLATION 5 / UNRESOLVED 4다. 각 검토자 배정·호스트 시간과 관측 구간은 execution 파일에 있다. 관측 구간은 오케스트레이션 지연을 포함하며 순수 모델 생성 시간으로 주장하지 않는다. 기존 Qwen의 GC-003 실패는 기존 기록으로 보존하며 새 실행의 성공으로 과거 기록을 고치지 않는다.

기계 검증은 17개 입력 연결·원시 JSON·사례 순서·라벨·일치 여부·72개 정확한 인용을 확인한다. 반론 및 판단 근거의 의미상 일관성도 실행자가 읽어 점검했다. 사용자 판단을 대신하지 않는다. 전체 회귀 결과는 regression-results.json에 기록한다.

최종 회귀: **15개 디렉터리 / 606 tests 통과**. 이번 재검토에서 외부 AGY 및 로컬 Qwen 호출은 0회다. 실제 Codex 검토 실행은 3개 세션, 검토 범위는 각각 6/6/5건이다. 최초 큰 출력의 절단은 trace에 남아 있으며 후속 전체 청크 열람으로 보완했다. SP-015는 원문 README 32,510자 및 후보 32,177자, packaging 전후 27/427자를 전체 검토했다.
