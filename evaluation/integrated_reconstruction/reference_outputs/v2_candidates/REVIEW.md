# 평가 기준 v2 재검증 및 참고 출력 후보 검토

이 문서는 clarification-02 이후 AI가 작성한 대조·반례 검토다. 사람 재검수·독립 사람 반례·최종 승인·모델 성능 평가가 아니다. 아래 기대 판정은 기준에 대한 AI의 해석이며 판정기나 모델의 실제 분류 결과가 아니다. 두 후보는 비유일 예시이고 실제 저장·발행 결과가 아니다. `post_revision_human_review`와 `gold_inclusion_approval`은 null이다.

## 대상과 실행 계획

- [IR-001 후보](IR-001.json): 원래 edit 문서 readme/usage 전체를 반환한다. 읽기 전용 자료는 반환·수정하지 않는다.
- [IR-002 후보](IR-002.json): 원래 edit 문서 design/ops 전체를 반환한다. ADR·주간 보고는 반환·수정하지 않는다.
- [계보](manifest.json): v1 입력·v1 참고 출력 및 평가 기준 v2/clarification-02의 경로·해시와 후보·이 검토 기록의 해시를 연결한다. 기존 기준의 reference_output_path는 역사 v1 경로로 유지하며 후보는 이 manifest에서 따로 선택한다.
- 순서: 기준·반례 대조 → 전체 후보 작성 → 스키마·인용·권한·보존 검사 및 변조 테스트 → 공식 전체 회귀 검증 → 기계 검증 결과 별도 기록. 실제 적용·골드 동결은 하지 않는다.

## IR-001 — 역할·실행·권한 경계

근거는 [기준 v2의 evidence](../../criteria/v2/IR-001.json) 및 [v1 입력](../../inputs/IR-001.json)에 고정되어 있다. E1/readme: “기부는 [후원 안내](FUNDING.md)에서 할 수 있습니다.”와 E2/funding: “금전 후원은 받지 않습니다. 대신 테스트 결과와 오류 제보를 환영합니다.”는 최신 정책의 우선순위를 확정할 자료가 아니다. 입력 명시 제약 0은 후원·기여·MIT 경로 보존, 제약 2는 개발 기록·참조 자료 읽기 전용과 새 문서 생성 불가다.

| 기준 | 후보의 처리 및 AI 대조 의견 | 근거 |
|---|---|---|
| D1 / Q1 | README는 소개·사용 안내 진입점이다. 설치 명령과 조건은 usage에 모았다. README 설치 상세 부재를 결함으로 보지 않는다. | E3, E4, E8 |
| D2 / Q3 / F1 | 기존 Donate 절을 한 글자도 바꾸지 않았다. 정책 충돌·양쪽 근거·질문은 제출물의 unresolved_questions와 이 검토 기록에만 두었다. README에 새 내부 의견·미확정 정책 설명을 넣지 않았다. 정책 확정과 문구 변경만 보류한다. | E1, E2; 명시 제약 0, 2 |
| D3 / Q4 | 기술적 결정은 읽기 전용 devlog에 그대로 있다. README 개발 이야기 전체도 유지하고 제거·분리 후보를 제출물에서 질문했다. 일기성 내용이 남은 것은 확인 대기이지 승인된 삭제를 가장한 것이 아니다. 중복 Python 조건은 의미를 유지해 usage에 모았다. | E7, E8, E11 |
| D4 / Q4 | 별도 유지보수 문서를 만들지 않고 usage의 유지보수자용 절에 기존 배포 명령·0.8.0 적용 사실을 두었다. 읽기 전용 이력은 수정하지 않고 연결했다. | E6; 명시 제약 2 |
| D5 / Q2 / F2 | 설치 명령, Python 3.11 이상, 색인 명령, 출력 상위 폴더 존재, 기존 파일 비덮어쓰기, 제목·입력 폴더 기준 상대 경로, 본문 비수정·비전송을 보존했다. 미검증 Windows·성능 보장을 추가하지 않았다. | E3, E4, E5, E8, E9, E10 및 release 전체 |
| 배치·적용 승인 | A를 선택한 검토 가능한 후보다. 초안의 배치·표현 확정과 실제 적용 권한은 별도 질문이다. 읽기 전용 기록 수정이나 별도 문서 생성 권한을 가정하지 않는다. | delivery.mode / delivery.required; D.confirmation |

중요한 경계: Q3의 README 금지는 **내부 검토 의견이나 미확정 정책을 새 본문으로 남기는 것**을 금지한다. 원래 존재하는 충돌 문구까지 승인 없이 제거·중립화하라는 뜻으로 읽으면 D2/F1과 이번 사용자 지시의 '기존 표현을 승인 없이 변경하지 않음'을 위반한다. 따라서 원문 보존 + 제출물 HITL 질문을 정당한 부분 보류로 해석했다. 이 해석과 일기성 원문 유지의 최종 적합성은 사람이 재검수해야 하며 AI가 확정하지 않는다.

## 기계 검사와 의미 검토의 경계

검증기는 스키마, 입력/기준/원본/후보/검토 기록 해시, 정확한 인용의 기존 기준 바인딩, edit/format_only 전체 반환, 읽기 전용 문서 비반환, 링크, 본문 해시, 후보별 동결 구간과 HITL 맥락 존재를 검사한다. 동결 구간은 **이번 IR-001 후보의 원문 보존 선택**을 검증하며 모든 유효한 출력의 문자열 정답 규칙이 아니다. 사용자 확인을 받은 다른 후속 버전에는 다른 선택이 가능하다.

CE-01~16의 의미 판단을 문자열 검사나 자동 테스트로 확정하지 않는다. 일반 의미 판정기·성능 평가를 구현하거나 실행하지 않았다. 내부 정책 의견 금지, 실행 정확성, 표본 한계의 의미는 사람이 전체 후보와 근거를 함께 읽어 재검수해야 한다. 후보의 미해결 질문은 실행 실패나 전체 작업 보류를 뜻하지 않는다.

남은 일: IR-001의 후원 정책 확인·일기성 정보 처리·권한과 배치/표현 검토, IR-002의 문서군 정책 위치·관찰 문장 검토, 세 사례 골드 포함 별도 승인. 사람 재검수 결과와 포함 승인은 이번 AI 기록으로 채우지 않는다.
