# IR-002 — 입력만 먼저 검토

입력 SHA-256: `086dc12ca81d3c866cb5369d74f9bed3c00bd46e80304084bc17fbdb6372878a`

다음 주 교대자가 이 문서 묶음만 보고 일상 운영과 장애 대응을 준비하고, 팀장이 현재 적용되는 설계를 확인할 수 있도록 문서를 정비해 주세요. 검토 가능한 후보를 부탁합니다.

가상 사내 서비스 QueueBridge의 운영 인계다. 설계서는 구조·선택 이유, 운영서는 일상 점검·대응, 주간 보고서는 특정 주의 결과를 남긴다. 승인된 변경 기록은 근거 자료다. 모든 사실은 아래 가상 스냅샷 안에서만 유효하다.

명시 제약:

- 주간 보고서와 승인 기록의 원문은 변경하지 않는다.
- 장애 연락처와 중단 조건은 운영서에서 즉시 확인 가능해야 한다.
- 날짜·수치·적용 조건·표본 범위를 보존한다. 새 운영 명령이나 승인 사실을 만들지 않는다.
- 설계서와 운영서의 문체는 한다체로 정리한다.

# ADR-07
승인일: 2026-11-11. 적용: 2026-11-12부터.
외부 API 제한 때문에 운영 환경의 실패 재시도 간격은 60초로 한다. 개발 환경은 30초를 유지한다.
작업 ID 중복 판별과 완료 ID의 24시간 보존은 바꾸지 않는다.
대기 건수가 500건을 넘으면 신규 배치를 중단한다. 당직자가 확인하기 전에는 재개하지 않는다.
오전 09:00 점검, 지연 10분 이상 지속 시 연락, #queue-oncall과 대시보드 Q-1은 계속 사용한다.
2026-11-11까지는 운영 환경도 30초였다. 과거 기록의 수치를 소급 변경하지 않는다.
~~~~
