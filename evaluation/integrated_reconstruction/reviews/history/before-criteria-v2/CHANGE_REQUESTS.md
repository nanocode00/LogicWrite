# 통합 골드셋 사람 검수 및 수정요청

## 기록 범위와 정확성

PR #36에 대해 이번 사용자 지시로 제공된 검수 결과를 기록한다. 평가 기준·입력·답안·참고 출력의 실제 수정은 수행하지 않았다. 모든 수정요청은 **미반영**이다. 두 사례 모두 골드 포함 보류이며 `gold_inclusion_approval`은 null이다.

사용자 최초 판단과 AI 초안 열람 후 대조·반례 검토는 서로 다른 단계다. 이번 지시에는 최초 판단의 원기록, 초안 열람 순서·범위, 검수 시각·서명, 독립적인 사람 반례 검토의 실시 근거가 제공되지 않았다. 따라서 `initial_judgment`, `initial_evidence`, `counterreview`는 null로 보존한다. ChatGPT를 통한 검토를 독립적인 사람 반례 검토로 기록하지 않는다. 이번에 제공된 사용자 판단은 `final_judgment`에 기록하되 골드 포함 최종 승인을 뜻하지 않는다. 확인되지 않은 시각·서명·근거·중재·승인 사실은 만들지 않는다.

기존 스키마가 `status`를 `pending_human_review`로 고정하므로 그대로 유지한다. 실제 판정과 미해결 상태는 본 문서와 JSON 서술 필드로 보존한다. 입력의 기존 해시와 v1 입력·답안·참고 출력·해시 및 기존 계보는 보존한다. 후속 실수정은 별도 버전·새 해시·부모 버전과의 계보로 관리하고 재검증해야 한다. IR-003은 변경하지 않는다.

## IR-002

**판정: 조건부 통과, Q1 수정 후 재검증 필요. 골드 포함 보류.**

| ID | 대상 | 수정요청 및 판단 근거 | 처리 상태 |
|---|---|---|---|
| CR-002-01 | Q1 | 설계서와 운영서에 동일한 내용을 반드시 반복하도록 요구하지 않는다. 문서군 전체의 정확성과 일관성을 평가하도록 아래 수정안을 반영한다. | 미반영 |

Q1 수정안(사용자 제공 원문, 아직 평가 기준에 미반영):

> 문서군 전체에서 2026-11-12 이후 운영 환경 60초, 개발 환경 30초라는 현행 정책과 적용 시점을 정확하게 확인할 수 있어야 한다. 각 문서는 자신의 역할에 필요한 조건을 제공하며, 동일한 조건을 서술하는 경우 문서 간 충돌이 없어야 한다.

사용자 판단:

- 네 문서의 역할을 유지한다.
- 설계서의 인계 절차를 운영서로 이동·통합하는 방식을 권장한다.
- ADR-07의 현행 정책을 반영하되 과거 기록을 소급 변경하지 않는다.
- 주간 관찰 사실은 기간·표본 한계를 명시하면 설계서에 남겨도 된다.
- 제한된 관찰로 일반적인 안정성을 단정하지 않는다.
- 필요한 안전 조건의 반복을 허용한다.
- 대안 A/B 모두 유효하다.
- D1~D4, Q2~Q4, F1~F3은 유지한다.

미해결: Q1 실제 수정과 재검증, 필요한 재검수, 별도의 골드 포함 승인. 이번 작업에서는 수행하지 않는다.
