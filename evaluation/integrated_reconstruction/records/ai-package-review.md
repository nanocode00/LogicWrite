# AI 패키지 검토 기록

2026-11-13. 작성 세션의 대화 이력을 제공하지 않은 별도 Codex 검토자가 패키지·입력·답안·전체 예시·검증기를 읽었다. 입력만 본 골드 반례 검수나 독립 사람 검수가 아니다. 사람 승인/정식 골드의 근거로 사용하지 않는다.

| 발견 | 재현과 조치 | 재확인 |
|---|---|---|
| IR-002 예시가 대시보드 Q-1에서 지연도 조회할 수 있다고 추가 | 입력은 Q-1을 대기 건수에만 연결한다. 지연 점검과 Q-1 대기 건수 확인을 분리했다. | 별도 검토자가 근거 범위 수정 확인 |
| `format_only`가 공백 제거 후 비교하여 `12건`→`1 2건` 등도 허용 | 숫자 분리·단어 결합 테스트 2개가 수정 전 실패함을 재현했다. 공백으로 구분된 토큰 목록을 비교해 경계를 보호했다. | 수정 후 별도 검토자도 19 tests OK 확인 |

검토자의 IR-001/IR-003 예시 평가는 명시된 Q와 대체로 부합한다는 AI 의견이다. 모든 의미 문제의 부재나 라이선스/표본 독립성·사람 정답 승인을 보증하지 않는다. 서식 검사는 보수적인 어휘 검사이며 일반 Markdown 의미 동일성 판정기가 아니다.
