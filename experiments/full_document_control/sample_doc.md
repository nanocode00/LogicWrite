# 로컬 런타임 설치 안내

로컬 에이전트 런타임 v0.4.0은 외부 클라우드 업로드 없이 작업 폴더 안에서 파일 검색과 테스트 실행을 수행한다. 기본 요청 제한 시간은 30초다.

## 지원 환경 및 패키지

| 플랫폼 | 최소 버전 | 설치 패키지 |
| --- | --- | --- |
| Ubuntu | 22.04 LTS | `runtime-linux-x64.tar.gz` |
| macOS | 14.0 | `runtime-macos-14.pkg` |

```bash
tar -xzf runtime-linux-x64.tar.gz
./install.sh --port 8765
```

---

## 운영 제약 및 주의사항

- 오프라인 모드는 사전 다운로드된 모델 캐시(`~/.cache/local-runtime`)가 존재할 때만 동작한다.
- macOS 패키지는 초기 실험 빌드이므로 자동 업데이트를 지원하지 않으며 수동으로 재설치해야 한다.
