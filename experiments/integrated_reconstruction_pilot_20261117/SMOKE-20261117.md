## 차단 근거와 범위

현재 `.env`의 키와 **정확히 같은 바이트**를 가진 `.env` blob이 로컬 Git 객체 저장소에 있다.
일치 blob은 로컬 `refs/codex/turn-diffs/`의 capture/checkpoint **tree** 두 개에서 참조된다.
2581개 로컬 Git 객체를 검사한 감사 시점의 경로/객체 근거는 `smoke-20261117/git-secret-audit.json`에 있다.
파일 내용·키 값·인증 헤더는 기록하지 않았다.

현재 인덱스에서 `.env`는 추적되지 않는다. 검사한 일반 로컬 브랜치/remote-tracking 이력에서는
이 blob을 찾지 못했고 `.env`의 일반 커밋 기록도 관측되지 않았다.
따라서 **GitHub PR이나 원격 브랜치 커밋에 키가 올라갔다고 단정하지 않는다.**
로컬 Codex 스냅샷 Git 객체에 저장된 사실과 원격 유출 여부는 별개다.

실행기 검사는 일반 커밋뿐 아니라 snapshot tree·dangling 객체까지 보수적으로 확인한다.
발견한 키를 사용해 테스트하지 말라는 요청에 따라, 검사를 완화하거나 해당 ref를 무시하지 않았다.
키 상태·실제 endpoint·가격의 인증 GET보다 앞에서 차단했으므로 서버의 $0.25 한도,
잔여 금액, endpoint의 현재 실행 가용성은 **미검증**이다. 사용자가 설정했다고 한 한도를
실측 검증으로 대체해 기록하지 않는다.

실제 시도 명령과 종료 상태는 `smoke-20261117/live-attempt.log` 및
`live-attempt/credential-safety.json`에 보존했다. 명령은 다음 형태이며 종료 코드 1이었다.

```sh
python3 experiments/integrated_reconstruction_pilot_20261117/run.py --execute --smoke --output experiments/integrated_reconstruction_pilot_20261117/smoke-20261117/live-attempt
```

같은 출력 경로는 재사용할 수 없다. 호출이나 자동 재시도는 일어나지 않았다.
키·스냅샷 정리 없이 폴더만 새로 만들어 재실행해도 같은 보안 검사에서 차단된다.

자동 보안 검사와 AI 의미 의견은 `smoke-20261117/result-summary.json`에 구분했다.
실제 응답 파일을 만들거나 참고 출력을 덮어쓰지 않았다. Core·골드·평가 기준은 변경하지 않았다.

## 재개에 필요한 사용자 조치

현재 키의 폐기·재발급을 권고한다. 새 키도 lifetime 최대 $0.25 한도로 설정해야 한다.
로컬 Git 객체에 남은 이전 키와 Codex snapshot ref 정리가 별도로 필요하다.
일반 브랜치 이력을 임의 재작성하거나 로컬 ref/객체를 삭제하지 않았다.
실행기의 전체 객체 검사는 이전 키 형식도 탐지하므로 **키 교체만으로 자동 통과한다고 보장하지 않는다.**
스냅샷 정리는 보존 범위를 확인한 별도 작업이어야 한다.
재개 시에는 보안 검사·키 상태·endpoint 가격을 다시 확인한 뒤 새 디렉터리에서 smoke 1회만 실행한다.
나머지 비교군은 이번 권한 범위에 포함하지 않으며 사용자 실측 검토 전 실행하지 않는다.
